# Flippin' Isaac website

Static site hosted on Cloudflare Pages. Every push to `main` deploys automatically.

- `index.html` — the whole site (prices, reviews, policies live in `DEFAULT_CONFIG` near the top of the script)
- `images/` — photos. Replace a file with the same name to swap a photo.

Cloudflare Pages settings: framework preset **None**, build command **empty**, output directory **/**.
